## 📌 Keypoints by PPT Slide

### Slide 1: Problem & Intro
- **Problem**: Capacity building for statistical officers (NSSO, CSO) is time-based, not competency-based.
- **Solution**: **DIKSHA** — Outcome-focused, adaptive AI competency platform for MoSPI & Mission Karmayogi.

### Slide 2: 6 Core Solution Pillars
1. **AI Profiling**: Ingests designation, role, and experience.
2. **Topological Gap Detection**: Evaluates current vs target role levels across 4 domains.
3. **Prerequisite Roadmaps**: Orders foundational skills before advanced topics using graph algorithms.
4. **iGOT Mapping**: Pairs gaps directly with iGOT Karmayogi course modules.
5. **Generative MCQs**: Dynamic AI quiz creation from uploaded documents using Gemini AI.
6. **SM-2 Spaced Repetition**: Calculates memory decay to recommend timely revisions.

### Slide 3: Technical Architecture
- **Backend**: Python 3.13 + FastAPI + Pydantic contracts.
- **Frontend**: Next.js 16 App Router + Tailwind CSS + Recharts + Framer Motion.
- **Algorithms**: Kahn's DAG Topological Sorting + SM-2 Spaced Repetition Decay Formula.
- **AI Layer**: Google Gemini 3.6 Flash + Structured JSON Enforcement + Sub-50ms Fast Cache + Heuristic Fallback.
